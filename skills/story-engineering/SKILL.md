# Story Engineering

## Overview
Short video wins on retention, not prose. Every 60s story = hook → tension → payoff → CTA.

## Frameworks
| Framework | Essence | Best for | 60s mapping |
|---|---|---|---|
| Mini Hero's Journey | ordinary world → challenge → transformation → new reality | documentary/true-story | setup → tension → payoff |
| Open Loop | question unresolved until final 5s, "I'll show you X, but first..." | best completion rate, TikTok | hook → payoff |
| Problem-Solution | name problem in 1 sentence, agitate cost ~5s, 70% on the fix | explainers/motivation | hook + solution |
| Stacked Micro-Payoffs | small payoff every 8-10s | listicles/facts | entire middle |
| Before-After-Bridge | show AFTER first, then bridge | transformations/results | payoff-first |

## The 60-Second Beat Sheet
| Time | Beat | Rule |
|---|---|---|
| 0-3s | Hook | recognition/tension, text overlay for sound-off |
| 3-8s | Context | name the problem or open the loop |
| 8-45s | Body | ONE promise only, micro-payoff every 8-10s, no dead air |
| 45-55s | Payoff | close the loop / reveal |
| 55-60s | CTA | one ask — save/follow/part 2, never generic "like and comment" |

Word target ~150-160.

## Hook Science
Hook strength = relevance × clarity × tension × credibility. Sequence: Recognition → Tension → Proof → Reward.

Formulas: curiosity gap; stakes-first; POV flashback ("On [date], I..."); loss/stakes ("lost everything because of one..."); contrarian; open loop; specific number ("$8,400. One mistake."); visual proof.

## Real-Based Story Rules
Real beats fiction:
- Loss stories beat win stories — stakes are instant
- Specificity creates credibility — real numbers/dates/places
- POV/turning-point hooks drop viewer inside the event
- Honest messy details build trust
- One promise only
- Manufactured drama gets called out fast

## Validation Checklist
- Hook ≤3s
- One promise
- Stakes/conflict in first 10s
- Payoff before 80%
- CTA in last 10%
- 130-180 words
- Real story: ≥1 verifiable anchor (number/date/place)

## Common Mistakes
- Cold open on logo/intro
- No connective tissue between points
- Multiple promises
- Payoff after CTA
- Invented quotes in true stories
